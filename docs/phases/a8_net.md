# Phase A8: network, security, robustness

Read first: CLAUDE.md "Multiplayer", `scripts/network/net.gd`, `body_net_sync.gd`, `scripts/gameplay/race_session.gd`, `cabin.gd`, `scripts/audio/*`, `scripts/core/port_opener*` and `room_code*`, `docs/DEVELOPMENT_PLAN.md` risks. Zero cost: player-hosted only, no paid servers.

Deliver:
1. **Security audit and fixes**: every RPC listed in a table (who may call it, what the host validates, a rate limit): any_peer RPCs validated against the roster and role; sane size/rate limits per peer (voice packets, requests, cans, shock); malformed args never crash; names sanitised and length-limited, no BBCode/control characters; a join version check; session flood protections (max pending peers, a join timeout, per-IP attempts if possible); client-driven car snapshots sanity-checked by the host (speed and teleport limits: flag and correct or drop, a cheat must not win a stage: gates validated with a plausible time); kick and per-peer mute for the host and each player; streamer mode (hide room code and IP). The join version check must be impossible to forget: `Net.PROTOCOL_VERSION` (A4 and A5 changed RPC signatures and added the `time` setting and the seat packets without bumping it) is derived from, or pinned by a test against, a fingerprint of every RPC's name and argument list plus the settings keys, so a change without a bump fails the suite; a peer with another version is refused with a clear message in its language. No secrets anywhere in the build; save files read defensively (a corrupt settings or records file never crashes); document in `docs/SECURITY.md`.
2. **Getting through home routers**: today UPnP plus LAN codes, and Radmin VPN as the fallback. Research and implement the best free option for CGNAT homes: UDP hole punching with a free public rendezvous/relay (netfox.noray is the known candidate: MIT addon plus a public noray server; verify current availability and terms with a web search, keep the addon small, pin the version), or a documented fallback. If a third-party server is used, make it optional, configurable, and fail over cleanly to the other codes; never send more than needed; the owner approved no extra download for this, so if an addon must be downloaded, implement against a design that can be finished once it is approved and report that clearly: do not download code without approval (allowed: reading docs and web pages).
3. **Reconnect and host loss**: a dropped client can rejoin the running race into its seat within a grace period (the car waits on the road or a bot holds it), late state sent (positions, cabin, damage, gates, events fired, settled boulders, map state); a host leaving ends the race gracefully with results so far and everyone back at the menu with a message. Host migration only if simple; otherwise documented as not supported.
4. **Bad networks**: a network simulation mode for tests (packet loss 5 %, 150 ms ping, jitter) in the tools (a small UDP proxy or engine options) with assertions in `tools\nettest.ps1`: cars stay smooth (snapshot buffer adapts), no desync of cabin state, voice stays intelligible (jitter buffer), gates and results right. Fix what breaks.
5. **Six players**: a 6-client soak test (`tools\nettest.ps1 -Clients 6` or a new script, headless, an hour-long mode for overnight and a short mode for CI): no errors, memory stable, bandwidth measured (per client up and down; record in `TEST_PLAN.md`).
6. **Crash and log handling**: a log file with versions and errors in `user://logs`, a "report a bug" button that opens the folder and a web page (itch.io page placeholder), no telemetry.
7. **Voice**: mu-law at 16 kHz uses ~128 kbit/s per talker: look for a cheap improvement with GDScript only (lower rate 8-12 kHz with a good filter; VAD gating) and report the numbers; TwoVoIP Opus needs a download approval (not approved yet): report as a pending option.

Done means: table in `docs/SECURITY.md`, tests per rule, nettest with simulation passes, soak numbers in TEST_PLAN, flow test passes, commits on main, docs updated. Report exactly what could not be tested without other people or real routers.
