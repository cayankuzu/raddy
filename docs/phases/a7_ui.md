Motorsport premium, restrained: dark translucent panels, one strong accent, crisp type, tabular figures, animated transitions (150-250 ms), no neon sci-fi, no default Godot look anywhere. Everything built in code with one design system (`UiTheme`): colours, type scale, spacing, components (button, panel, tabs, slider, dropdown, toggle, list row, key prompt, toast, modal).

Deliver:
1. **Design system** in `UiTheme` (or a small family): theme resource built in code, fonts embedded, focus states, hover and press animation, sounds. Works from 1280x720 to 4K (a UI scale setting, safe areas), TR and EN text never overflow.
2. **Main menu**: the real car on a stage backdrop in 3D (a small scene: the Milano '95 in a team paint, dust motes, slow camera), logo wordmark RADDY, Play (create/join), Solo practice (if A6 added it), Settings, Credits, Quit; version; a clean join-by-code flow with validation, clear errors, recent code, paste button.
3. **Room**: crew cards per team with colour, name, seat, ready lights; voice indicators; stage card (name, biome, length, medal times, record, a mini map of the road from the same RouteGraph), race settings in a clean panel (host edits, others see), room code with copy and a streamer "hide" toggle; start button with the reason it cannot start. Everything readable at a glance.
4. **Race HUD, by role** (GAME_DESIGN §8), broadcast quality: rev counter arc with shift lights, big gear, speed; damage silhouette (the car from above: zones tinted, hood/bumpers state); stage progress bar with crew markers; split times with green/red delta pop; recovery prompt with a progress ring and key glyph; who is talking; shock gun darts; toast feed; countdown lights (rally start lights) with a real feel; finish moment. Never the road ahead on the driver's HUD. Settings: HUD scale, Minimal / Off mode. Remove dev text from the player's screens. Navigator: the paper map is the main thing: make it readable (it must fill the view when open, zoom defaulting so the next corners are big enough to read at 1080p, notes column large, the next note highlighted, a trip meter: distance since the last reset, reset key), the live car arrow clear, wrong ways clear.
5. **Results**: podium with the crews and their cars' colours, times, medals with a small animation, awards (A6), a share card: a key saves a PNG of the results (`user://`, opens the folder) to post on social media; buttons for next/same stage for the host.
6. **Settings**: tabs (Gameplay, Controls, Audio, Video, Accessibility): all existing options plus UI scale, colour-blind team colours (Okabe-Ito based alternative palette), motion options (camera shake, head motion, FOV slider), text size, subtitles for system messages; rebinding for keyboard and gamepad with glyphs, a wheel calibration page (press pedal -> axis detected, invert, saved; steering range).
7. **Onboarding**: a first-run role explanation (driver/navigator, what the map is, how to talk) in a few short illustrated cards, key prompts in the race for the first minutes by role; tips on loading screens; pause menu; a proper loading screen with stage name, the road's shape and a tip.
8. **Gamepad everywhere**: every menu navigable by D-pad/stick and A/B, focus visible; mouse hides when using a pad; prompts switch between keyboard and pad glyphs automatically.
9. **Credits**: all licences (`ASSET_LICENSES.md`) with the CC BY lines.

10. **What the earlier phases left for this one** (all exist in the game, see CLAUDE.md): the navigator's trip meter box in the cabin shows real numbers (`CarRallyKit.trip_display()`: distance since reset, reset key, average speed; lit at night); seat position and field of view options (`CockpitCamera.BASE_FOV` 62, the seats' eyes: forward/back and height within what the mirrors and dials allow, `tests/unit/vehicles/test_seat_view.gd` holds the limits; A5's review measured the driver's interior mirror only 60 % in frame at rest (77 % at 60 km/h, 88 % at 100): the default must show at least 85 % of it with the road still the star, and a test holds that); the room shows the time of day, the room mode and modifiers (A6) as clean chips; the intercom's state, the hands' refusals ("hands full") and the gestures have their HUD places and key glyphs; the HUD's own rev counter and speed are optional now that the real dash works (HUD modes: Full, Minimal = only timing and prompts, Off); the wheel's pedal calibration that A2 left. The HUD must read at night without glowing into the dark (a dimmer night palette), in snow glare and against a low sun.
